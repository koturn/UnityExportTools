UnityExportTools
================

An export tool for generating .unitypackage and ZIP files for UPM.

## Usage

Create `ExportConfig.json` on unity project root.
The [`ExportConfig.json` file for this project itself](ExportConfig.json "ExportConfig.json") serves as an example of an `ExportConfig.json` file.
